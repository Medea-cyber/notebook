# Блокнот рассказчика (SillyTavern)

Раз в N сообщений модель получает скрытый промпт, перечитывает чат и сама решает,
что хочет реализовать, спросить или придумать про NPC и мир. Записи сохраняются
в этом чате и тихо подмешиваются в контекст, чтобы модель постепенно их вплетала.
Модель может ничего не записать (ответ NONE), отметить задумку выполненной (DONE)
или вычеркнуть её (DROP).

## Установка в Termux

    termux-setup-storage
    cd ~/SillyTavern/public/scripts/extensions/third-party/
    unzip ~/storage/downloads/npc-notebook.zip

Перезапусти SillyTavern. Панель — в «Расширениях», раздел «Блокнот рассказчика».

## Что важно знать

- Размышление — отдельный запрос к текущему API с полным контекстом чата.
- Пока внизу не появилось уведомление, лучше не отправлять следующее сообщение.
- Если модель отвечает не командами, смотри «Последний ответ модели» и правь промпт.
